# 云服务生产闭环与 OneAPI 托管模型

- 编号：`004`
- 状态：实施中
- 创建时间：2026-11-20
- 关联需求：[001 微信登录与托管模型云服务](001-wechat-auth-hosted-model-service.md)

## 1. 背景与问题

当前独立云服务仍是 loopback 开发沙箱，仅支持显式启用的模拟身份和沙箱充值。目标业务已确认使用邮箱一次性验证码登录、一次性购买永久点数、按模型 token 用量结算，并由独立运营后台管理版本化商品与模型价格；OneAPI 只承担模型调用数据面。

## 2. 目标与非目标

### 目标

- 建立云端邮箱 OTP 无密码登录和可撤销会话。
- 建立永久有效的整数点数充值、预留、结算和不可变账本合同。
- 通过固定 OpenAI-compatible Chat Completions 数据面接入 OneAPI，按已发布模型价格版本调用。
- 建立独立 cloud admin、RBAC、一次性首管引导与追加式审计。
- 保持未配置生产依赖时 fail closed，并以 fake 服务完成本地行为验收。

### 非目标

- 本阶段不接真实支付、真实 SMTP、真实 OneAPI/模型或执行生产部署。
- 不集成 OneAPI 管理 API，不暴露管理 Key。
- 不改本地 workspace 身份、权限、数据表、BYOK 或 `internal/app`。
- 不把 SQLite 沙箱视作生产数据库，不虚构点数费率。

## 3. 用户场景与需求

- 作为云端创作者，我希望用邮箱验证码登录并购买一次性点数，以便按托管模型的实际 token 用量消费。
- 作为运营管理员，我希望在独立权限边界中管理已版本化商品与模型价格，并审计管理操作。

## 4. 范围与边界

- 涉及服务/数据：`backend/cmd/cloud`、`backend/internal/cloud/**`、云需求与架构/技术设计文档。
- 外部系统或依赖：邮件发送器、OneAPI Chat Completions 数据面；首期支付使用沙箱适配器。
- 权限与数据归属：cloud account/session 与 cloud admin/session 均独立于本地 workspace；服务端数据库是账号、价格、订单和账本权威来源。
- 明确不改变的现有行为：本地服务、BYOK、沙箱 subject 登录及沙箱支付边界。

## 5. 验收标准

- [x] OTP 单次消费、过期、错误次数上限、请求频控、会话撤销和账号枚举中性响应通过行为测试。
- [ ] 商品/模型价格版本在任务创建时冻结；当前已冻结模型价格快照，后台版本化维护 API 尚未开放。
- [x] 任务创建先按最大输入与输出上限原子预留，成功后按可信 usage 结算并释放余量；未知状态不重发且保留预留。
- [x] OneAPI fake 验证固定路径、服务端认证、模型映射、usage 和超时行为；客户端不能提供上游地址、密钥、模型 ID 或费率。
- [x] 独立 cloud admin 的一次性 bootstrap、RBAC、跨账号/越权拒绝和审计基础约束通过行为测试；运营写 API 尚未开放。
- [ ] 云存储迁移不创建本地 workspace 表；账本追加式；密钥不进入响应、日志或文档。
- [ ] 生产环境必需项缺失时启动失败；不执行真实 SMTP、支付、OneAPI/模型调用或部署。

## 6. 约束与决策

- 已确认决策：邮箱 OTP 无密码；一次性充值；点数永久有效；按模型输入/输出 token 整数费率；按最大输入 token 与本次输出上限预留；OneAPI 只用于模型调用；首期沙箱支付；独立管理员及一次性 bootstrap；后台版本化维护价格。
- 待确认问题：生产数据库/迁移与备份方案、域名/TLS/可信代理、SMTP/秘密管理、OneAPI 模型与 usage 语义、实际费率和未知任务对账责任人。
- 兼容性/迁移约束：云服务与本地 workspace 数据隔离；已发布迁移不改写；已有沙箱数据需兼容。
- 安全、隐私、费用、频率或合规约束：验证码与会话秘密只存摘要；账本只追加；未知上游状态不得按零成本结算或自动重发。
- 依赖或禁止事项：禁止真实服务凭据、真实付费调用、真实支付、生产 OAuth/邮件发送或未经授权的部署。

## 7. 技术方案

### 职责与数据流

HTTP -> cloud handler -> cloud identity/catalog/task/admin service -> cloud-only persistence；模型调用经固定 OneAPI 数据面适配器。价格和账本规则归服务端，客户端不能指定可信上游配置。

### API / 数据 / 配置变更

- API：逐阶段新增邮箱认证、任务与管理员接口。
- 数据库迁移：新增云专属版本化数据结构与迁移；保留既有沙箱数据。
- 配置与部署：邮件、生产数据库、TLS/可信代理、OneAPI 等外部参数缺失时生产启动失败。
- 文档：同步架构与技术设计；只记录已实现和实际验证状态。

### 失败、权限和恢复

验证码单次消费；任务、预留、usage、账本结算使用事务和幂等约束。调用超时、缺少或异常 usage 时进入待核对状态并保留预留，不自动重发。
