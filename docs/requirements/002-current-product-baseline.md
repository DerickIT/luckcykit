## 1. 文档目的与事实口径

本文不是未来云服务设计，也不是对现有实现的认可或承诺。它将当前仓库中可观察的用户能力、行为边界和外部依赖整理成需求基线，方便后续讨论哪些能力要保留、改变或删除。它不要求按现有代码结构重写。

状态标记：

- **现状可用**：桌面本地工作区的活动 UI/API 链路中存在可操作入口。具体能力仍可能要求完成配置或满足运行环境条件。
- **条件可用**：依赖用户配置、宿主能力、插件、功能开关或外部服务；缺少条件时应显示不可用原因或错误。
- **后端存在/UI 不可达**：后端合同或页面实现仍在，但当前路由/桌面产品入口未开放。不得按普通用户当前可用功能描述。
- **退役/历史保留**：旧功能已退出运行路径，历史数据或兼容结构仍保留。
- **规划/讨论**：尚无本仓库当前产品实现，不属于现状验收。

事实优先级：当前桌面路由和组合根、实际页面/服务调用、后端合同与测试、迁移/配置代码、现有专题文档。README 和功能清单用于发现主题，不单独证明能力仍可访问。遇到冲突时记录冲突，不用旧文档覆盖现状。

## 2. 产品范围与运行边界

### 当前产品定位

LuckyTV 是 AI 影视与短剧创作工作台，核心工作发生在用户自己的桌面工作区：组织画布、项目和素材，配置模型渠道，发起文本/图片/视频/音频或本地媒体处理任务，并将结果继续用于创作、复用和导出。

桌面应用由 Wails 宿主前端和 Go 本地服务组成。工作区按单机单 owner 运行；workspace owner 是本机数据身份，不是互联网账号。项目数据和模型凭据不因登录变化而转移。

### 运行形态

| 形态/能力 | 当前基线 | 状态 |
| --- | --- | --- |
| LuckyTV 桌面工作区 | Wails + React 前端 + Go loopback API + SQLite/本地资源目录；桌面启动和存储目录迁移由原生能力提供 | 现状可用，原生能力依平台而异 |
| 浏览器本地开发/运行 | 页面可使用本地浏览器持久层；桌面与纯浏览器运行的资源、能力不同 | 条件可用，不等同于桌面发布验收 |
| `cmd/server` 服务端形态 | 提供可独立运行的 Go 服务入口，但组合的仍是本地工作区、SQLite/本地资源和同一桌面 API 路由图；不等于自有云 SaaS | 条件可用，部署参数需按当前配置核实 |
| Hosted/server 历史兼容代码 | 部分 API、页面分支、远端同步和托管存储合同仍留在仓库；桌面本地能力边界由运行组合根与 `workspace-mode.ts` 决定 | 后端存在/条件可用；不能据此推断当前桌面产品启用 |
| LuckyTV 自有账号、微信登录、支付宝支付、额度账本和自有托管模型云 | 只有需求/架构讨论材料；没有当前自有云服务实现 | 规划/讨论，见需求 001 |

### 数据与信任边界

- 桌面工作区的画布、项目、素材元数据、任务、模型渠道配置和资源文件以本机 Go/SQLite/数据目录为主要事实来源；具体域的草稿、偏好和纯浏览器模式状态可由 scoped IndexedDB/localForage 保存。
- 浏览器缓存可用于读取加速、草稿恢复或后端不可用时的明确降级；本地缓存成功不能表述为服务端持久化成功。
- 不建立桌面工作区数据的隐式云同步。用户主动调用模型、插件或外部集成时，相关输入会按其协议离开本机；这不是项目数据库同步。
- 用户自有模型渠道（BYOK）凭据由本地工作区配置边界管理。插件和模型服务是扩展/生成能力，不是数据权威。
- 可选参考素材对象存储仅服务于需要公网引用素材的生成传输，不代表画布、项目或素材库云同步。
- 本机 owner 身份与未来云账号必须分离。未来云服务方向以需求 001 及其讨论稿为准，不属于本基线的现状要求。

## 3. 用户与核心旅程

当前主要用户是单人创作者/制作者，在一台本地工作区中完成构思、生成、整理、剪辑与交付。系统还允许用户安装扩展，或让获授权的本机外部 Agent 操作当前工作区。

核心旅程：

1. 首次启动并完成必要的模型渠道配置，确认工作区、存储和外部能力状态。
2. 从首页或画布库创建自由画布，导入/上传素材，组织节点与关系。
3. 在独立创作页、画布节点、项目章节或助手中生成/编辑内容；提交前查看可得的费用估算和参数，确认后等待任务结果。
4. 在失败、断线或应用重启后查看真实任务状态；只在系统判断允许时重试或取回原结果，避免重复付费提交。
5. 将生成结果保存到画布、个人素材库或项目资产中，继续编辑、复用工作流或进入时间线剪辑。
6. 通过本地导出、诊断包或桌面文件保存完成迁移、交付和问题排查。
7. 需要时安装 Skills/插件，或通过本机 MCP 将明确授权的工作区操作交给外部客户端。

## 4. 功能需求基线

### 4.1 启动、首页与工作区导航

- **BR-001（现状可用）**：启动后应读取公开外观配置或安全回退，再显示工作区，避免品牌初始化过程短暂显示错误外观。
- **BR-002（现状可用）**：首页应提供新建画布入口、核心能力导航和最近画布；最近画布展示预览及更新时间。读取失败必须显示错误和重试入口，不能伪装成空列表。
- **BR-003（现状可用）**：用户应能在主导航中进入画布库、个人素材库、创作页、Skills、模型/存储设置、MCP 连接等已开放区域。插件中心按功能开关开放。
- **BR-004（现状可用）**：桌面侧栏应支持必要的折叠、主题和新手引导/工作区级动作；本机 UI 偏好与画布内容数据分开持久化。
- **BR-005（状态差异）**：当前 `/tasks` 路由重定向到首页。任务 API 和任务页实现仍存在，但任务中心 UI 不作为当前可达入口；任何重写验收不能仅凭隐藏页面代码认定任务中心已交付。

### 4.2 画布库与画布编辑

- **BR-010（现状可用）**：用户应能创建、打开、重命名、复制、整理和删除画布；画布库支持文件夹/搜索/排序等组织能力，并提供适用的导入导出与回收操作。
- **BR-011（现状可用）**：画布应以可编辑的节点图表达文本、图片、视频、音频、分镜、文件夹/分组、工作流和扩展节点；用户可创建节点、编辑属性、连线、移动、缩放、框选、多选、复制粘贴、撤销/重做与自动整理。
- **BR-012（现状可用）**：用户应能上传、拖放或粘贴媒体并将个人素材引用到画布；资源上传、预览、下载及节点引用由统一资源身份管理，删除受项目/画布/任务/历史等引用保护。
- **BR-013（条件可用）**：图片、视频和音频节点应提供与媒体类型匹配的预览、下载、媒体处理和生成入口。浏览器无法直接解码的媒体可以按需生成本地预览，但源文件与素材身份必须保留。
- **BR-014（现状可用）**：画布保存应避免旧页面或旧缓存静默覆盖较新内容；版本冲突时保留可恢复草稿并提示解决。并发内容只有在实现可证明无冲突时才能自动合并。
- **BR-015（条件可用）**：有后端快照支持时，用户可浏览、只读预览和恢复历史版本；恢复应创建新版本，不改写历史版本。版本记录和媒体文件应分离，历史引用中的媒体不得被误删。
- **BR-016（现状可用）**：画布外观（跟随全局/固定主题/受限自定义背景和网格）、视口、面板及临时工具选择按其所属范围保存；外观偏好不得意外覆盖画布内容。
- **BR-017（现状可用）**：画布库与短剧项目库是不同概念，应在侧栏和命令面板分别提供独立入口。短剧项目通过 `/dramas` 进入；`/projects`、`/project` 和 `/canvas` 保持原有画布库/画布路由语义，不得混用两类实体。

### 4.3 独立创作页与对话

- **BR-020（现状可用）**：`/create` 应提供基于对话的文本、图片、视频创作流程，支持提示词编辑、模型与参数选择、参考素材、附件和生成结果预览。
- **BR-021（现状可用）**：用户应能保存、查询、重命名、继续、导入/导出或删除创作对话；对话变更需要版本冲突处理，临时媒体文件不应被误当作对话事实源。
- **BR-022（条件可用）**：当模型/渠道有可信价格信息时，提交前展示估算及其适用范围；未知价格必须明确标识，不得按零费用展示或将估算冒充最终账单。
- **BR-023（条件可用）**：可流式显示文本生成进度，允许取消尚未完成的前端等待，并保留真实后端任务状态。取消等待不等于上游任务已取消或退款。
- **BR-024（现状可用）**：生成结果可继续编辑、下载或交接到画布/项目；结果尚未持久化或交接失败时必须区分已生成、已保存和已关联状态。
- **BR-025（条件可用）**：语音输入/转写及提示词优化依赖浏览器、模型或插件能力；仅在能力实际可用时呈现，并保留用户原始输入，失败不得覆盖草稿。

### 4.4 模型渠道与生成能力

- **BR-030（现状可用）**：用户可配置自有模型服务，包括支持的内置渠道、自定义兼容渠道及安装的协议插件；可读取模型目录、手动添加模型 ID、配置用途/能力/参数，并选择默认模型。
- **BR-031（现状可用）**：读取目录成功不等于模型可生成。用户应能执行真实连通/生成测试；测试任务状态和产物应可追踪。
- **BR-032（现状可用）**：模型能力和协议差异应通过服务端能力合同或插件协议呈现，不能依靠前端硬编码模型名称推断参数、费用或支持范围。
- **BR-033（现状可用）**：渠道配置保存应有明确的草稿/确认语义、错误定位和并发版本保护；密钥不得回显到前端或进入日志、任务正文、URL、诊断包。
- **BR-034（条件可用）**：文本/图像/视频/音频生成支持按相应模型能力提交；参考素材按协议传输要求使用本地资源、内联内容、用户启用的参考对象存储或协议声明的链接。缺少传输方式应指出受影响素材，不创建失败后仍伪装成功的任务。
- **BR-035（条件可用）**：费用预估只展示有依据的报价/计价方式，并区分预留金额、近似金额、可变费用、未知费用和 BYOK 供应商实际收费。估算接口不得隐式创建任务或扣费。
- **BR-036（现状可用）**：可访问的任务创建、批量生成、超分、视频智能擦除、转写、深度处理等入口必须固定当次提交参数与稳定操作身份，提交未知时不得悄悄用新身份重发。

### 4.5 任务、进度与恢复

- **BR-040（后端现状可用；部分 UI 不可达）**：后端任务合同应支持按工作区读取任务、日志和文本事件，提交、取消、重试及适用的原任务恢复；所有对象操作均校验本地 owner 和任务归属。
- **BR-041（现状可用）**：任务状态以服务端持久化事实为准。前端展示 `task.outcome` 所表达的阶段、是否可重做/取回和原因，不自行覆盖服务端结论。
- **BR-042（现状可用）**：文本任务事件流使用递增事件游标，断线可按最后事件继续读取；刷新或重启后可按原 task ID 恢复观察，不把 task ID 当作事件游标。
- **BR-043（现状可用）**：任务应区分排队/执行、交付中、成功、失败、等待取回、不可恢复等状态；生成完成和媒体已保存/已绑定画布是不同阶段。
- **BR-044（现状可用）**：可安全恢复时沿用原任务与原请求身份，不重复触发上游收费提交。未知结果、过期凭证或证据不足时应停止自动重试，并告知可能的费用不确定性。
- **BR-045（现状可用）**：任务失败文案应尽可能保留可供用户修正的原因，同时脱敏上游地址、密钥和内部请求信息；诊断只补充证据，不替代任务状态权威。
- **BR-046（路由限制）**：当前任务中心页面不可达。任务页中的历史过滤、列表和详情交互不得写入当前产品验收，除非路由重新开放并完成 UI 验收。后端任务接口可用于活动创作流程及诊断，不因中心页面退场而等同于任务系统整体退役。

### 4.6 项目、短剧和分镜生产

- **BR-050（现状条件可用）**：项目域用于组织剧本/章节、画布、镜头、资产、制作产物和导出流程；项目与普通画布保持不同实体和生命周期。
- **BR-051（路由恢复后待验收）**：短剧项目列表/创建页通过 `/dramas` 开放，详情及章节、分镜、资产、画布和剪辑视图使用 `/dramas/:projectId/...`，不得落入本地画布兼容重定向。现有 `/projects/:projectId` 与 `/project/:projectId...` 仍作为旧画布链接兼容入口，按原行为重定向到画布。AI 大纲依赖可用文本模型；页面可达不代表所有依赖能力均已配置。
- **BR-052（条件可用）**：项目有章节/集数时，应能编辑、排序和导入正文，并按章节组织分镜制作。AI 大纲、分镜规划、资产抽取及媒体生产要求相应文本/图像/视频模型。
- **BR-053（条件可用）**：镜头脚本、引用资产版本、生成产物和当前采用版本应可分别追踪；修改上游资产/镜头不应静默覆盖历史产物，过期关系应可见。
- **BR-054（条件可用）**：角色、场景、道具等抽取先产生待确认候选；用户可审核、合并或拒绝，再进入项目资产。系统不得把模型输出直接当作已批准的项目事实。
- **BR-055（未确认可达范围）**：项目时间线编辑、语音转写与成片导出涉及插件插槽及本机 Whisper/FFmpeg 等依赖；没有对应插件或运行组件时应报告缺失，不得假设默认安装即可完成。

### 4.7 个人素材与资源管理

- **BR-060（现状可用）**：个人素材库应区分图片、视频、音频、文本和模型等内容，以及个人资产和生成历史；支持预览、详情、元数据维护、搜索/筛选、文件夹、分页和必要的批量操作。
- **BR-061（现状可用）**：用户可导入、上传、下载、导出和在适用范围内删除个人资产；ZIP/工程导入导出应报告进度、错误和部分结果，不得把未落盘的浏览器缓存说成服务端保存。
- **BR-062（现状可用）**：资源删除前检查画布、项目、任务、工作流、快照等引用；被引用时保留资源并提供阻止原因，物理文件删除失败时不得先删除元数据。
- **BR-063（条件可用）**：Eagle 等外部素材源不是本地素材事实来源。桌面本地 profile 的选择器不应隐式读取/写入外部源；仅在显式支持该 profile/连接时开放。
- **BR-064（现状可用）**：存储用量、画布文档上限、上传限制与媒体预览缓存清理应按真实后端数据展示；上传额度、文件存储和浏览器缓存属于不同状态。

### 4.8 Skills、插件与工作流复用

- **BR-070（现状可用）**：Skills 为创作流程提供可版本化说明和参考文件；用户应能浏览详情、确认安装、启停、检查更新、回退版本、编辑/导入/导出或发布草稿（具体市场能力依服务可用性）。
- **BR-071（现状可用）**：Skill 的安装不代表执行条件已满足。助手须按固定版本和当前权限读取技能；运行包内脚本应遵循产品确认设置。Skill 文本本身不能授予权限。
- **BR-072（条件可用）**：插件可贡献模型协议、画布节点、页面、工具栏/编辑器插槽、资产动作和工作流能力。安装、更新、启停和卸载应有明确确认与来源信息。
- **BR-073（安全边界）**：第三方客户端插件运行于同一页面/本机环境，声明权限主要用于告知用户，除非某执行路径明确实施授权检查，不可将其描述为完整沙箱。用户应能识别插件来源和信任风险。
- **BR-074（现状可用）**：画布可将符合合同的生成/处理步骤封装为版本化可复用工作流；固定模板版本、输入替换、输出、运行记录与稳定操作 ID 应可核验。模板删除不得抹掉运行历史或破坏现有画布实例。
- **BR-075（条件可用）**：工作流执行复用既有任务队列与媒体处理能力；本地确定性处理可不需要模型，生成步骤仍可能产生供应商费用。缺少适配器的节点不得伪装为可自动执行。

### 4.9 创作助手、MCP 与外部 Agent

- **BR-080（现状可用）**：画布创作助手围绕当前画布和用户明确提供的素材生成草案/提案；涉及画布写入或付费生成时，须由可信 UI 展示确认并经服务端验证。
- **BR-081（现状可用）**：当前内置助手以 Durable 会话及官方 pi SDK 宿主运行；会话、工具调用、用户确认、技能版本、权限范围和画布操作回执应遵循后端状态。旧 JSONL 只读历史不会恢复旧执行循环。
- **BR-082（现状可用）**：本机 MCP/外部 Agent 使用登记凭据访问共享操作合同；读写范围、对象归属、revision、稳定 operation ID 和回执由 Go 服务端校验。浏览器不得接触 owner/宿主凭据。
- **BR-083（条件可用）**：桌面端可为支持的本机客户端提供一键接入；其他客户端使用手动配置。用户应能查看、验证和撤销客户端授权。
- **BR-084（退役/历史保留）**：旧 `/agent/*` 运行 API、旧 cloud_agent 通用任务及旧 Agent 自动记忆压缩已退役；旧表和历史数据保留，不代表旧功能仍可运行。

### 4.10 设置、诊断、更新和桌面运行时

- **BR-090（现状可用）**：设置页应提供模型渠道/默认模型、存储、参考素材传输和诊断入口；可选深度组件只在原生宿主具备时展示。
- **BR-091（现状可用）**：存储设置可在桌面宿主支持时迁移完整工作区数据目录；迁移前后必须保留数据库、资源及加密密钥的一致性，不能只搬数据库文件。
- **BR-092（现状可用）**：诊断包可导出有界且脱敏的运行/任务/错误证据，导出前显示范围/数据量；默认排除提示词、密钥、Cookie、完整 URL 和请求正文。
- **BR-093（条件可用）**：桌面启动、原生媒体组件、应用更新和离线安装依平台打包与运行环境；健康检查只证明入口可用，不证明生成、媒体、升级和恢复链路已验收。
- **BR-094（当前范围外）**：测试语音录制页面为实验/原型入口，不作为正式创作会话功能验收。

## 5. 关键业务对象与数据权威

| 对象 | 当前权威来源 | 关键关系/约束 |
| --- | --- | --- |
| 本地工作区 owner | Go workspace 服务生成的本地身份 | 单安装单 owner；不等于云账号 |
| 服务运行时 | `cmd/desktop` / `cmd/server` 进入同一 Go workspace runtime 组合 | server 可执行入口不表示独立云账号/账务系统 |
| 画布 | 桌面 SQLite/本地仓库；纯浏览器形态为 scoped IndexedDB/localForage | revision/CAS 写入；媒体引用资源 ID；草稿与视口偏好分离 |
| 项目/章节/镜头 | Go 项目域与 SQLite 合同（项目 UI 可达性目前受路由限制） | 章节/镜头/资产/任务显式关联；镜头产物版本化 |
| 素材/资源 | SQLite 元数据 + 本机数据目录字节 | 删除按所有业务引用检查；浏览器媒体缓存不是事实源 |
| 模型配置 | 工作区本地配置文件与加密密钥；前端状态为镜像 | revision 保护；密钥不得经普通读取接口回显 |
| 生成/处理任务 | Go 本地任务持久层与 worker | task outcome 为生命周期权威；操作 ID 幂等；结果交付与业务绑定分阶段 |
| 助手回合/操作 | Durable 宿主和 SQLite 回合/操作记录 | 权限、会话、画布版本和操作回执相互绑定；模型文本不构成授权 |
| Skill/插件 | Skill 版本包/后端索引；插件清单、安装与本地运行态 | Skill 固定版本；插件来源/能力需可识别；第三方执行不默认沙箱化 |
| 画布偏好/主题等 | 浏览器 scoped 本地存储或画布文档（按字段定义） | 不得用偏好缓存覆盖业务内容事实 |

当前本地 schema 版本应以 `backend/internal/database/local_schema.go` 的 `CurrentSchemaVersion` 和迁移实现为准；写本文时为 v30。迁移细节与兼容条件见数据库专题文档，不在此重复作为另一份结构规范。

## 6. 外部依赖与失败边界

- **模型供应商**：用户配置的 API/协议；认证、限流、价格、模型能力、审核和可恢复性因供应商而异。供应商成功不等于结果已写入本地资源。
- **LuckyTV 官方算力旧连接**：现存客户端适配代码及 `/luckytv/connection*` 路由仍注册，但默认生产 origin `https://luckytv.app` 已停用，仅显式本地测试源允许。路由存在不代表生产账户、钱包或托管服务可用；不得将其写成当前自有云产品。
- **插件/Skill 市场与 GitHub/npm**：依市场和网络访问；外部包/脚本属于信任边界，安装或更新需用户确认和来源检查。
- **Eagle/参考存储**：可选外部服务；桌面本地 profile 不应在用户打开素材选择器时隐式访问外部素材源。
- **FFmpeg/Whisper/深度组件**：部分随桌面包提供，部分依本机配置、平台能力或外部服务；未就绪须明确失败。
- **Wails、WebView、系统代理、文件选择器和系统凭据/权限**：受操作系统及桌面打包环境影响；浏览器开发态不能代替原生桌面验收。

## 8. 面向重写的验收原则

重写不要求复刻当前实现细节，但在产品逐项决定去留前，应以以下行为作为现状对照基线：

- [ ] 新用户在无云账号/无网络时可启动本地工作区、读取/编辑已有项目与画布，并使用已配置且可达的 BYOK 渠道。
- [ ] 画布、素材、模型配置和任务各自有明确的权威存储；断网/进程异常时界面如实区分本地草稿、已落盘、已提交和已交付状态。
- [ ] 重启后能恢复本地资源、画布、可恢复对话和任务观察；提交结果未知时不以新操作身份自动重发可能收费的请求。
- [ ] 画布保存冲突保留用户工作；资产删除考虑所有业务引用，媒体文件故障不会造成元数据静默丢失。
- [ ] 各模型协议及能力可扩展；新增模型不要求在页面按模型名增加行为规则。
- [ ] 付费/高影响写入具有明确用户意图、服务端合同校验、稳定幂等身份及可读结果；模型/Skill/插件文本不能代替授权。
- [ ] 无插件、模型、FFmpeg、Whisper、市场或原生组件时，受影响能力明确报告未就绪，不伪装成空数据或成功。
- [ ] 功能页面只有在生产路由和可用配置下可达，才纳入“已交付”验收；隐藏/重定向实现单独列为待决定项。
- [ ] 运行形态矩阵分别覆盖 Wails 桌面、浏览器开发态及任何未来 hosted profile；不得以一条 profile 的测试代表其他形态。
